# Mascot-Customizer-Prototype
## Description:
A mascot-customization prototype for K-12 schools. Think of Bitmojis (https://www.bitmoji.com/) but with mascots. The client wants it built in Unity for easier compatibility with adding a gaming utility and crypto/NFT stuff later down the road (not in this current scope though).
###### Using Unity version [2021.3.0f1](https://unity3d.com/get-unity/download/archive) with the WebGL module.
